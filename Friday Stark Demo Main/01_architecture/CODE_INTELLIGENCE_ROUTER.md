# Code Intelligence Router

Use different memory layers for different questions:

1. **codebase-memory-mcp** — exact structural graph: symbols, callers, routes, dependencies.
2. **Graft** — concept/context map and blast-radius orientation.
3. **GBrain** — durable historical decisions, lessons, research and project facts.
4. **Exact source/runtime/tests** — final truth.

Recommended:
`structural query → concept query if needed → durable memory if relevant → open exact files only → implement → risk-sized tests`.

Generated summaries never outrank current exact source.
