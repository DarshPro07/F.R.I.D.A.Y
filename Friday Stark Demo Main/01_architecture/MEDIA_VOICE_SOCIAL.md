# Media, Voice and Social

## OpenMontage
AGPL-isolated media-production sidecar plus pipeline/Skill knowledge. Friday/Hermes owns the parent objective.

## Pipecat
Experimental voice/multimodal provider. Existing Friday LiveKit path remains production baseline until a benchmark proves Pipecat is better for a target class. Pipecat itself can use LiveKit transport, so benchmark integration rather than forcing replacement.

## Postiz
AGPL-isolated publishing/scheduling sidecar. ConnectorControlPlane handles OAuth/user auth. Friday permission kernel decides whether public publishing is authorized.
