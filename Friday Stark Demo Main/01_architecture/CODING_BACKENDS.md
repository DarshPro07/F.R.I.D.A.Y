# Coding Backends

Hermes-native stays the baseline.

OpenHands and Cline are supervised specialist backends.

Route to a specialist only if measured value exists for the current task class:
- sandbox/workspace semantics;
- stronger tool loop;
- compatibility requirement;
- success/rework advantage;
- capability Hermes-native lacks.

Forbidden pattern:
`Friday → Hermes → OpenHands → Cline → another planner`.

Benchmark same pinned coding tasks across Hermes-native/OpenHands/Cline:
success, fresh tokens, calls, first productive action, total time, rework, CPU/RAM, process count.
