# Research and Knowledge Fabric

- Vane: broad search/metasearch.
- Agent-Reach: platform-specific retrieval.
- Open Notebook: active source/notebook research.
- AnythingLLM: optional document/workspace compatibility.
- GBrain: durable verified shared Friday/Hermes knowledge.
- Canonical project files: source of truth where appropriate.

Flow:
`retrieve → inspect authoritative/primary material → analyze → notebook/workspace → verify → admit only durable conclusions into GBrain`.

Do not create another universal memory system inside AnythingLLM/Open Notebook.
