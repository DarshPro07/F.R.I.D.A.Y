# Adversarial Tester Prompt

After each slice, stop thinking like the developer.

Attack:
- duplicate stale processes;
- successful outer envelope with failed inner result;
- wrong-session/wrong-origin delivery;
- auth failure classified as connectivity;
- capability reported healthy while dependency is dead;
- MCP call returns but real side effect failed;
- ObjectiveRun lost after provider crash;
- unsafe mutation retry;
- secret leak;
- banking capture;
- hidden model calls;
- huge MCP/Skill context injection;
- unnecessary full suite;
- profile/browser confusion;
- AGPL/GPL code copied into Friday core;
- upstream update breaking adapter;
- cancellation ignored;
- process not cleaned up.

For each:
reproduce → capture evidence → identify root cause → smallest patch → regression → negative/mutation control → live retest.
