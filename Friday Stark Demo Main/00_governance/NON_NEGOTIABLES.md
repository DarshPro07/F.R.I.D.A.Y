# Non-Negotiables

1. Friday remains the single normal user-facing control layer.
2. Hermes remains mandatory for serious agentic execution.
3. No upstream may own or replace Friday's durable parent ObjectiveRun.
4. No plaintext credentials enter LLM context, logs, Skills, GBrain, research stores, or repo files.
5. Banking/authenticated financial-account content remains blocked before DOM/screenshot/OCR/vision capture.
6. Every upstream is untrusted until audited and pinned.
7. Preserve full upstream source depth, exact commit, license and update path.
8. Friday changes belong in adapters or explicit patch series, not silent upstream edits.
9. Copyleft/separate-license code is not copied into proprietary Friday core without a deliberate licensing decision.
10. Installed capabilities remain dormant until routed where practical.
11. Avoid duplicate browsers, memories, orchestrators, model calls, workers and full-suite runs.
12. Build state must survive compaction, model/tool changes and restarts.
13. User input is required only at true auth/MFA/secret/spend/irreversible/policy boundaries.
14. Tests alone cannot promote an integration; live behavior must pass.
15. An optional upstream crash must not crash or erase the parent Friday objective.
