# Performance and Token Benchmark

Capture before/after:
- success and factual correctness;
- fresh/cached tokens;
- model calls;
- tool/MCP calls;
- file reads;
- browser actions;
- first productive action latency;
- total latency;
- CPU/RAM peak;
- process count;
- rework.

Required A/B:
1. Hermes-native vs OpenHands vs Cline.
2. Existing Hermes browser vs browser-use for interaction.
3. Scrapling vs Maxun vs browser-use for extraction classes.
4. codebase-memory-mcp vs Graft vs combined.
5. existing LiveKit path vs Pipecat.
6. native research vs Vane/Agent-Reach/Open Notebook.

Do not accept upstream benchmark claims as Friday product evidence.

Promotion is about execution value, not smallest token count.
