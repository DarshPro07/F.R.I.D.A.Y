Friday Companion

Lets Friday see and operate the browser you are already signed into. Everything stays on this machine — the extension talks only to Friday on 127.0.0.1. It never reads saved passwords, never copies cookies, and will not type into a password field.

1. Pair with Friday

Paste the token from data/companion/token.txt in the Friday folder.

2. Sites Friday may work on while you are away

Without this, Friday can only act on a tab you have clicked the Friday icon on, one tab at a time. That limit is deliberate: unattended access to a site you are signed into is a decision, not a default.
