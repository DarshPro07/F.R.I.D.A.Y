# Not the design system

This file is superseded. Use [`DESIGN.md`](../../DESIGN.md) at the repository
root, which describes the interface that actually ships.

It previously held a generated design system — `#7C3AED` primary, `#A78BFA`
secondary, `#FAF5FF` background — a light-mode purple palette produced by a
tooling pass and never reconciled with the product. Friday's control room is
amber on black, and PRODUCT.md rules out purple explicitly. Nothing reads this
directory; the palette was wrong and it claimed to be authoritative
("strictly follow the rules below"), which is the worst combination a
documentation file can have.

Kept as a redirect rather than deleted so the path does not silently 404 for
anything that later looks for it.
