# Security Fabric

Strix is a restricted defensive capability.

Allow:
- local code owned by user;
- intentionally vulnerable local fixture;
- explicitly authorized staging/CI target.

Require explicit scope/authorization before any externally reachable target.

Deny:
- unauthorized third-party exploitation;
- credential theft;
- malware/persistence/evasion objectives.

Friday policy remains above Strix regardless of Strix agent behavior.
