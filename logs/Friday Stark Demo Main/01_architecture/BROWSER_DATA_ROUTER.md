# Browser and Data Router

```text
Need web work?
  |
  +-- deterministic/static/adaptive extraction -> Scrapling
  +-- interactive multi-step browser action -> existing Hermes browser or browser-use
  +-- persistent/reusable scraping robot -> Maxun
  +-- platform-specific research -> Agent-Reach
  `-- broad private metasearch/discussion/academic retrieval -> Vane
```

Do not run several for the same normal task. Use a multi-provider run only for an explicit benchmark/fallback evaluation.

Security:
- isolated browser contexts by default;
- user-signed-in browser access follows Friday permission policy;
- no banking/financial account capture;
- secret/cookie material not sent to the LLM;
- site policies, robots and applicable law remain enforced.
