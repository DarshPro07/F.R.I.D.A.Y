# DevOps Promotion Prompt

For the active slice verify:
- clean install from pinned source;
- dependency isolation;
- correct ports/processes;
- no logical duplicate services;
- health/start/stop;
- machine/app restart;
- logs contain no secrets;
- persistent data paths known;
- rollback/uninstall;
- CPU/RAM idle vs active;
- upstream license packaged;
- Friday production restart/check still passes;
- sidecar outage does not take down Friday.

Then run the live capability Golden Journey again from the restarted system.
