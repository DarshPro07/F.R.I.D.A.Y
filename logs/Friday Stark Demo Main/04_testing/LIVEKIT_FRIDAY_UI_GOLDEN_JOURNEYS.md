# Real Friday / LiveKit Golden Journeys

These must go through the normal user-facing Friday UI/LiveKit path.

## U1 Direct
Simple user question → no unnecessary backend.

## U2 Background capability
Start a real safe task; keep talking to Friday; execution continues.

## U3 Steer
Steer one active task; no duplicate WorkRun.

## U4 Stop
Stop one target; no ghost completion.

## U5 Invisible routing
Ask for:
- webpage extraction;
- interactive browser form;
- code dependency explanation;
- content polish;
- media production plan.
Friday chooses backend internally and does not make the user name the repository.

## U6 Provider crash
Kill a sidecar/MCP. Friday recovers or routes around it while preserving ObjectiveRun.

## U7 Restart
Restart Friday in a multi-step operation; resume from durable cursor.

## U8 Builder compaction
New Claude/Fable session reads BUILD_RUN_STATE and continues without re-auditing all upstreams.

## U9 Auth
A connector needs auth → existing ConnectorControlPlane parks/resumes automatically.

## U10 UI verification
Use Claude Chrome/browser tooling on the actual Friday UI; semantic/accessibility state first, screenshot/vision only when visual proof is needed.
