# Acceptance Matrix

| Gate | Required evidence |
|---|---|
| Pin | exact commit/tag/version/license |
| Audit | install/network/secrets/telemetry/privilege reviewed |
| Install | reproducible isolated setup |
| Upstream tests | pass or documented upstream limitation |
| Adapter | typed contract, parent objective remains Friday |
| Health | deterministic status |
| MCP | handshake/list/call/error/cancel/restart |
| Operation | real result independently verified |
| Failure | provider crash does not erase Friday objective |
| Restart | provider + Friday recover |
| Memory | build resumes after compaction/tool switch |
| Permission | kernel remains above upstream |
| Token economy | no unnecessary model/browser/worker calls |
| Process | no stale duplicate server/sidecar |
| UI | real Friday/LiveKit path where applicable |
| Secrets | zero model-visible plaintext secret |
| License | distribution boundary recorded |
| Rollback | disable/uninstall/restore procedure |
| Final | READY/PARTIAL/DISABLED/BLOCKED_EXTERNAL/REFERENCE_ONLY |

Cloning a repository is not integration.
