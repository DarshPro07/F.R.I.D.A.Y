## Coordination protocol

- The orchestrator (`friday-orch`) delegates via the `Agent` tool; it never
  writes production code itself and never forks.
- One agent = one scope (its owned paths). Parallel dispatch only when scopes
  are disjoint.
- `docs/plans/jarvis-agentic-team/` is the shared state; plans go in `.plans/`
  per Rule 1.
- `friday-monitor` runs the deterministic gate in 4 chunks, background, and
  reports counts only.
- An Opus review (`friday-tech-lead` for design, `friday-security-engineer`
  for anything credential/device-control-facing) precedes any "done".
- Token rule (Rule 15): skeleton views before full reads, <= 8 files / <= 400
  lines before the first edit, quiet tool output, <= 250-word reports with
  file:line evidence, follow-ups via `SendMessage` instead of a new dispatch.
- Every generated agent references `.claude/rules/14-friday-house-rules.md`
  and `.claude/rules/15-token-discipline.md`.

## Plugin install

`claude plugin install "<repo>\third_party\upstream\agents-team\plugins\agents-team"`
and `claude plugin marketplace add <plugin-dir-or-repo-root>` both fail — this
CLI version only installs from a marketplace with a real
`.claude-plugin/marketplace.json`, which the pinned upstream clone doesn't
ship (it ships a single `plugin.json`), and a source path inside
`marketplace.json` must start with `./` (no `../` escape), so it cannot point
out of the marketplace directory at the pinned clone directly.

Non-interactive workaround (no pinned-clone files modified): a marketplace
shim was created in the session scratchpad
(`.claude-plugin/marketplace.json`, `"source": "./agents-team"`) with a
directory junction `scratchpad/agents-team` -> the pinned
`third_party/upstream/agents-team/plugins/agents-team`, so the marketplace's
relative-path rule is satisfied without copying or editing pinned upstream
content.

```
claude plugin marketplace add "<scratchpad>"
  -> Successfully added marketplace: friday-local (declared in user settings)
claude plugin install agents-team@friday-local -y
  -> Successfully installed plugin: agents-team@friday-local (scope: user)
```

`claude plugin list` confirms `agents-team@friday-local` enabled, cached
independently at `~/.claude/plugins/cache/friday-local/agents-team` (a real
copy made at install time, not the junction) — safe even after the scratchpad
is cleaned up. The `friday-local` marketplace registration itself persists in
the user's global Claude Code config; removing it later
(`claude plugin marketplace remove friday-local`) is optional and does not
affect the already-installed, already-cached plugin.
